JSON output reference

Add --json to any command. Output is one JSON value on one line.

zones

An array with one object per domain:

Field Type Example
Domain string "example.com"
Account string "aws-default"
Provider string "ROUTE53"

explain

An array with one object per domain. Intents[i] explains Zone.Records[i].

Field Type Meaning
Zone.Domain string The domain
Zone.Provider string dnscontrol provider type
Zone.Nameservers string array Nameservers the provider reports, may be empty
Zone.Records[].Name string Full name, lowercase, no trailing dot
Zone.Records[].Type string A, CNAME, TXT, R53_ALIAS and so on
Zone.Records[].Value string Target, address or joined TXT text
Intents[].Kind string See the kinds below
Intents[].Service string Company behind the record, empty when unknown
Intents[].What string One plain sentence

Kinds: nameserver, mail-in, mail-bounce, spf, dkim, dmarc, mail-policy, mail-brand, web, verification, certificate, cert-policy, infrastructure, unknown.

check

An array with one object per domain:

Field Type Meaning
Domain string The domain
Provider string dnscontrol provider type
Findings[].Check string delegation, spf, dkim, dmarc or dangling
Findings[].Severity string critical, warn, info or unchecked
Findings[].Name string The record or domain the finding is about
Findings[].Why string What's wrong and why it matters
Findings[].Fix string What to change

Findings is null when a domain has no findings.

Example: list criticals with jq

dnsplain check --all --json | jq -r '.[] | .Domain as $d | (.Findings // [])[] | select(.Severity=="critical") | "\($d) \(.Check) \(.Name)"'
