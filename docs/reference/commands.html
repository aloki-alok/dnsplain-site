Command reference

Commands

Command Does
dnsplain zones Lists every domain hosted by the accounts in your credentials
dnsplain explain <domain> Shows what each record of one domain is for
dnsplain explain --all Explains every domain and prints how many records were recognized
dnsplain check <domain> Checks one domain for problems
dnsplain check --all Checks every domain
dnsplain help Prints usage

Name one domain or use --all. Doing both is an error.

Flags

Flags can go before or after the domain. Everything after -- is treated as a domain, not a flag.

Flag Meaning
--creds <file> Path to a dnscontrol-format creds.json
--all Run on every domain
--json Print JSON instead of text. See JSON output.

Where credentials come from

dnsplain uses the first of these that exists:

  1. The file given by --creds
  2. ./creds.json
  3. ~/.config/dnsplain/creds.json
  4. The AWS SDK's default credentials, used as one Route 53 account named aws-default

Exit codes

Code Meaning
0 Finished. No critical findings.
1 check found at least one critical problem
2 dnsplain failed: bad arguments, unreadable credentials, or a provider error

Supported providers

dnsplain includes every DNS provider dnscontrol supports: 77 in dnscontrol v5.7.2. To count them for the version you built:

grep -c '/providers/[a-z0-9]*"$' "$(go list -m -f '{{.Dir}}' github.com/DNSControl/dnscontrol/v5)/pkg/providers/_all/all.go"
