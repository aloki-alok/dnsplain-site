dnsplain

Find every domain you own, see what each DNS record is for, and catch problems before your mail lands in spam or someone takes over a subdomain.

dnsplain reads from 77 DNS providers through the dnscontrol engine. It only reads. It never changes your DNS.

Install

go install github.com/aloki-alok/dnsplain/cmd/dnsplain@latest

The code repository is private during early access.

Commands

Command What it does
dnsplain zones Lists every domain your provider accounts host
dnsplain explain <domain> Says what each record is for, in plain words
dnsplain check <domain> Finds broken delegation, SPF, DKIM, DMARC and dangling CNAMEs. Use --all for every domain.

If you use AWS, there's nothing to set up. Other providers need a creds.json: see Connect other providers.

Example

$ dnsplain check example.com
example.com  ROUTE53
  warn      dangling   old.example.com
            points to a host that no longer exists. Visitors get an error.
            fix: Delete this CNAME, or point it at a live host.

0 critical, 1 warn, 0 info, 0 unchecked across 1 domains

If a lookup fails, the check shows as unchecked. dnsplain never guesses.
